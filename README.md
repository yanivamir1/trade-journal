# Trade Journal

אפליקציית מעקב אחרי טריידים אישית — בודקת סטטיסטית אילו החלטות (רגשיות
וטכניות) הובילו בפועל להצלחה. HTML/CSS/JS פשוט, בלי build step, בלי שרת.

הדרישות המלאות נמצאות ב-`TRADE-JOURNAL-REQUIREMENTS.md` בתיקיית ההכנה.

## הרצה מקומית

צריך שרת סטטי כלשהו (הקבצים משתמשים ב-ES modules, לא עובד עם `file://`
ישירות). לדוגמה:

```
npx serve .
```

ואז לפתוח את הכתובת שמודפסת בדפדפן.

## מצב נתונים נוכחי (חשוב)

- **הנתונים נשמרים כרגע רק בדפדפן (localStorage), בלי סנכרון בין
  מכשירים.** זו החלטה מכוונת לשלב הראשון — ראו סעיף "החלטות פתוחות"
  בקובץ הדרישות. כדי לסנכרן בין טלפון למחשב היום: הגדרות ← "ייצוא
  לקובץ" במכשיר אחד, ואז "ייבוא מקובץ" במכשיר השני.
- **מפתח Finnhub** מוטמע כברירת מחדל (אותו מפתח מ-`STOCK-PRICE-FEATURE.md`),
  ניתן להחליף בהגדרות.
- **ATR (שבועי/יומי) לא זמין אוטומטית** — נבדק בפועל שה-endpoints
  הרלוונטיים ב-Finnhub חסומים בתוכנית החינמית. השדות בטופס פתוחים
  למילוי ידני. אפשרות עתידית: ספק נוסף (כמו Alpha Vantage) למדד הזה בלבד.
- **ייבוא נתוני עבר**: קובץ `seed-trades-import.json` בתיקיית ההכנה
  מכיל את 42 הטריידים ההיסטוריים (מומר מ-`trade_journal_example.xlsx`)
  בפורמט שהאפליקציה יודעת לייבא דרך הגדרות ← "ייבוא טריידים מהיסטוריה".
  קובץ `portfolio_data.json` (גם בתיקיית ההכנה) ניתן לייבוא דרך מסך
  "שווי תיק" ← "ייבוא נתוני עבר". **קבצים אלו מכילים נתונים כספיים
  אמיתיים ולכן לא נכללים ב-repo הזה** — הייבוא קורה מקומית בדפדפן בלבד.

## מבנה

```
index.html          שלד + ניווט
styles.css
js/
  storage.js        localStorage (טריידים, שווי תיק, הגדרות)
  finnhub.js        Live Price (מחיר + P/E; ATR ידני)
  stats.js          חישובי win-rate / P&L לפי כל פילוח
  statsView.js       מסך הסטטיסטיקות
  portfolio.js       מתודולוגיית ניטרול הפקדות/משיכות + גרף
  trades.js          רשימת טריידים + מודלים Add/Sell
  settingsView.js     מפתח API, ייבוא/ייצוא, איפוס
  charts.js          גרפים (SVG קו, בארים) בלי ספריות חיצוניות
  constants.js        ערכי enum ותוויות בעברית
  modal.js            עזר כללי למודלים
```
